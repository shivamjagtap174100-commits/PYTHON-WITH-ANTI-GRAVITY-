## 📚 Course Curriculum (12 Step-by-Step Lessons)

### Module 1: Introduction to Python & Sequence of Instructions
- **Lesson 1.1:** *Your First Program & The `print()` Function* — Strings, quotation rules, and comments (`#`).
- **Lesson 1.2:** *Variables & Sequence of Instructions* — Storing data, variable naming conventions, and modern f-strings.

### Module 2: Type Conversions & Arithmetic Operators
- **Lesson 2.1:** *Basic Arithmetic Operators (`+`, `-`, `*`, `/`)* — Calculating store bills, sums, and float division.
- **Lesson 2.2:** *Floor Division, Modulo & Exponents (`//`, `%`, `**`)* — Remainders, whole-number division, and powers.
- **Lesson 2.3:** *Type Conversions (Casting)* — Converting between `int()`, `float()`, `str()`, and `bool()`.

### Module 3: Conditional Statements (Decision Making)
- **Lesson 3.1:** *If & Else Statements* — Comparison operators (`==`, `!=`, `>`, `<`, `>=`, `<=`) and indentation rules.
- **Lesson 3.2:** *Elif & Logical Operators (`and`, `or`, `not`)* — Multi-grade classifications and compound checks.

### Module 4: Loops & Loop Control Statements
- **Lesson 4.1:** *The `for` Loop & `range()`* — Counting from 1 to N, loop boundaries, and repetition.
- **Lesson 4.2:** *While Loops & Loop Controls* — Condition-based repetition, counters, `break`, and `continue`.

### Module 5: Data Structures & Nested Data Types
- **Lesson 5.1:** *Lists & Indexing* — Ordered collections, 0-based indexing, `.append()`, and `len()`.
- **Lesson 5.2:** *Dictionaries (Key-Value Pairs)* — Labelled lookups, updating keys, and querying data.
- **Lesson 5.3:** *Nested Data Types* — 2D matrices (`matrix[0][1]`) and lists of records (`users[0]["username"]`).

*Bonus:* **Free Practice Sandbox** — Unrestricted Python coding playground to write and execute any code.
